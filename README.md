# C Programming — Loops, Arrays & Bitwise Operators

## Topics Covered

### 1. Loops

Loops are used to repeat a block of code.

* `for` loop
* `while` loop
* `do-while` loop
* Using loops for input and calculations
* Counting values using loops

### 2. Arrays

Arrays are used to store multiple values of the same data type.

* Array declaration
* Array initialization
* Array indexing
* Accessing array elements using loops
* Taking user input in an array
* Displaying array elements

Example:

```c
int prices[5] = {120000, 230000, 1000, 1200, 3400};

for (int i = 0; i < 5; i++)
{
    printf("%d", prices[i]);
}
```

### 3. Bitwise Operators

Bitwise operators work directly on the binary bits of numbers.

* `&` — AND
* `|` — OR
* `^` — XOR
* `~` — NOT
* `<<` — Left Shift
* `>>` — Right Shift
